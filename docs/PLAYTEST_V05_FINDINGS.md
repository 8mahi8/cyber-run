# CYBER RUN｜V0.5 試遊評価と次期品質基準（2026-10-22）

## ユーザー試遊結果
- V0.5.0: 開始直後にキャラクターが右へ流れ画面外へ消える。原因は physicsStep に `runner.x + 6` を渡していたこと。V0.5.1で修正。
- V0.5.1: プレイ自体は可能。しかし**簡単すぎる**、**展開が単調**、**面白くなかった**。
- 重要: 自動テストの通過はゲームの面白さを保証しない。ユーザーの実機評価を品質判定の最優先にする。

## コースの実データの監査
- 登録パターン13種類（休息パターンを含む）。
- 配置定義の内訳: low 17、bar 6、tall 1、platform-bar 1、moving 0。
- スタート時に利用可能なパターンは5種類で、そのうち1つは障害物のない休息区間。
- 一部の足場コースは足場を使わずに突破できる。別解自体は歓迎だが、空中アクションを体験する機会が少ない。
- 結果: 名目上のパターン数に対して、要求するアクションの種類が少ない。

## 次の実装はV0.5の単純な難易度増加ではなく、コース体験の改修
1. **高速連続操作**を主役にする。単純な地上ジャンプ2連・低天井反復だけに頼らない。
2. **空中足場の活用**: 足場への着地、足場上のしゃがみ、自然落下、落下直後の回避を操作テーマにする。下入力で足場をすり抜ける機能は追加しない。
3. **新しい展開の対比**: 地上ラッシュ／空中移動／自然落下・着地コンボ／強いジャンプ／短い息継ぎ。
4. **距離メートル勝負を維持**。コインなし、HP3、レア回復、無料運用、ランキング後回し。
5. 少なくとも1つのノーダメージ突破ルートと複数フレームの入力猶予を保証。別解は許容する。
6. コース単体だけでなく、4コース以上の連結、加速、画面内の視認時間も検証する。

## 出荷前に必要な品質ゲート
- 位置安定性: 開始/再開/画面回転/ジャンプ/足場の着地と自然落下でキャラが画面外へ流れない。
- 描画ライフサイクル: pause/resume を連打しても requestAnimationFrame が多重にならない。
- マップ: 多くの乱数シード、最高速度、遅い実行環境でも座標破綻と不可能な連結がない。
- 内容: 最初の短時間から地上/空中/しゃがみ/着地後の操作が変化する。名前だけ違うコースを多様性として数えない。
- 実機: スマホと学校iPadのタッチ操作をユーザーが評価するまで「面白さは確認済み」と報告しない。

## リリース方針
動作バグの修正は既存試遊版へ反映。**新しいコース設計は開発ブランチで検証してから試遊版へ**。ランキングは今は実装しない。
