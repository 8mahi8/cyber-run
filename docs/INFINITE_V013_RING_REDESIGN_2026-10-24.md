# CYBER RUN V0.13｜水色リングの操作・コイン軌道の設計修正（2026-10-24）

## ユーザーからの指摘と原因
- 本人がV0.12を実機試遊し「そもそもその操作ならコインの軌道が合ってない」「操作がよく分からない」と指摘。コインは道標であるため、**操作と一致しないガイドのまま出すべきではない**。
- V0.12のTWIN HALOは［初期ジャンプ→第1リング自動→中間で手動2段ジャンプ→第2リング自動］という隠れた入力連携を要求。物理リプレイで確認した金コインは、その後の高度が画面上端より外（最小約-67px）まで飛び出す。画面の上に消える道標と、初見で知らないタイミングの空中ジャンプが原因。
- GitHubの物理計算を多数パラメータ探索し、**手動ジャンプ1回＋リング2つの自動跳躍だけで、コインが画面内に入る**構成を選んだ。

## 実装
1. `extra-motifs-v1.js` のTWIN HALOを「**最初に1回跳ぶ → 1つ目のリングで自動跳躍 → 2つ目のリングでも自動跳躍 → 着地後しゃがむ**」へ変更。中間の隠し2段ジャンプは削除。
2. リングは第1段100×64px・地上から80px、第2段140×70px・地上から55px。第2リングの時間位置を1.75秒に、穴を中心1.775秒×幅1.55秒へ再設計。穴は依然としてリング両方を必要とする。最高速度を含む物理テストでは、**どちらか片方のリングだけでは通過できない**。
3. `H.makeGuideCoins` によるコイン軌道生成はそのまま利用。新しいphysics-scriptの実走行traceから配置を全面再計算。難度0〜250秒のTWIN HALOではコインのyは49〜356px程度に収まる（ground=370、描画キャンバス540）。以前のように上へ消えない。
4. `infinite-level-v1.js` でリングが出現する区間の**手動ジャンプ入力位置**を物理速度で計算した `segment.jumpCues` を生成し、`game-infinite-v1.js` が紫の「↑ TAP」を表示。リング本体には「AUTO ↑」を表示し、押す場所と自動バウンド箇所を視覚的に区別。
5. `core.js` の自動発動リングで直近発動IDを `runner.lastAirBoostId` に記録。ゲーム側が新しいリング発動を検知し、上昇中に触れた場合も **AUTO ↑ の文字と専用の水色エフェクト**が確実に出るよう改善。物理ジャンプ速度等は変えていない。
6. 初期操作説明 `infinite-playtest-v1.html` も正しい「TWIN HALOは最初の1回だけ手動でOK」へ更新。旧V0.12の説明を撤回。
7. 新しい本人試遊候補は **main:playtest-v28/index.html** に独立追加。GitHub Pages URLの想定は https://8mahi8.github.io/cyber-run/playtest-v28/ 。旧V0.12 `/playtest-v27/`、学校Google Sites版、Firebaseやランキングは変更せず。
