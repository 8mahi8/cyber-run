# CYBER RUN — candidate V0.6 (development only)

高速エンドレス・アクションランナー。ブラウザ1ファイルへ結合できるHTML/CSS/JS。無料運用。

## V0.6で変更したこと
- 速度: 400→最大1,150 px/s。最高速度に達するまで約100秒。
- 操作テーマの短いアクションコース22種類。序盤から地上・空中・トンネル・動く障害物を混在。
- **ジャンプ台を新設**。踏むと強く跳ね上がり、任意で二段目のジャンプが可能。新ボタン不要。
- 一方通行の空中足場、自然落下、高速ジャンプ・しゃがみ連携を継続。
- 空中足場コースの抽選比率を上げ、同一テーマの連続を抑制。
- 速度上昇時の配置時刻を移動距離の積分から計算することで、実機と検証の時刻差を減らした。
- iPad相当の画面で先のコースを見やすくするためカメラの横幅を調整。
- 距離スコアだけ。コイン廃止済み、HP3、レア回復は維持。ランキングは未実装。

## 品質管理

- Node.js: `node --test tests/*.test.js`
- 乱数100シード: `node tools/gameplay-quality-gate.cjs`
- 実ブラウザでの各種入力とスクリーンショット: `python tests/visual_play.py`
- QA専用操作スクリプトを実ブラウザで使った長時間リプレイ: `python tests/autoplay_browser_qa.py`。QA版では内部入力を操作しているが、通常ゲーム本体には自動プレイを入れない。
- Chromiumでの検証は学校iPad Safari実機検証の代替にはならない。
- 2026-10-22: Node.js自動テスト19件成功。100シードの生成監査で序盤空中34.3%、動く障害物66コース/30秒サンプル、ジャンプ台77コース/30秒サンプル。
- QA専用の想定入力で、スマホ・iPad等4画面×計16回の120秒走行（最大速度1150）を完走、HP3維持。現実の指操作で同じ成功率を保証するものではない。
- 無操作・ジャンプ連打などの雑な入力では早期に敗北することを確認。楽しいかどうかは操作の質と視認性の主観レビューが別途必要。
