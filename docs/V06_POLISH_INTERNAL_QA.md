# CYBER RUN｜V0.6開発版 内部レビュー（2026-10-22）

**公開判定: 保留（GitHub Pages / Google Sitesへは未反映）**

## 今回の実変更
- 2段階の空中足場を実際に渡る `sky-stepdown` / `sky-stepduck` コースを追加。見た目だけでなく両方の着地を物理リプレイで確認。
- ジャンプ・着地・ジャンプ台の瞬間的な視覚効果を追加。ゲームの距離スコア、障害物判定、乱数生成には影響させない。
- 地上の低い障害物、吊り下げゲート、動く障害物、高い壁の輪郭を描き分け、判定範囲を視覚的に把握しやすくする。
- 4:3 iPad相当画面の描画オフセットを変更。物理座標は変えない。
- 開発ブランチ用GitHub Actionsの物理・難易度・多様性ゲートを追加。

## 実施したQA
- ローカルNode.js自動テスト: 既存20件を含む全21件合格（route-replay test追加後）。
- 100シード、最初の30秒における地上/空中コース分布: 約64% / 36%。動く障害物も生成。
- Chrome/Chromiumのタッチ画面相当（スマホ横・iPad相当）で120秒のコース想定操作16回: すべてHP3、最高速度1150まで到達、JavaScriptエラーなし。
- 放置プレイ12シードの平均生存約6.3秒、0.24秒間隔のジャンプ連打12シードの平均生存約14.0秒、想定ルートは各12シードで100秒完走。これらは**ゲーム体験の指標**であり、人間の楽しさを示す証拠ではない。
- ギミック追加前の古い route-replay test がバネを扱っておらず、GitHub CIで1件失敗。放置せず、同じ物理引数で検証するように更新。

## 公開前に残る判断
1. Chromeの自動操作やスクリーンショットからは、人間が「楽しい」と感じるかを厳密には判定できない。
2. Safari実機の長押し、2段ジャンプ、復帰、処理落ちは未検証。
3. 序盤の操作のリズム、難易度カーブ、後半の視認性についてさらに画面レビューが必要。
4. CI成功を確認しても、それだけでは公開しない。

## ルール
ユーザーが求めるのは**高速で連続操作を成功させる気持ちよさ**。通過可能性やコース数だけを満たして試遊版を更新してはいけない。新要素は開発ブランチで検証し、満足できるまでmainを変更しない。
