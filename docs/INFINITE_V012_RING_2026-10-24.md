# CYBER RUN｜V0.12 水色ジャンプリング到達性の改善（2026-10-24）

## 実機フィードバック
ユーザーは GitHub Pages のV0.11を試遊中に、空中の水色リングのジャンプについて「ジャンプボタンを押すの？」「ジャンプの高さが足りなくない？」と指摘。これは操作の勘違いとして片付けるべきではない。水色リングは接触時に自動跳躍するが、「TWIN HALO」では、初回ジャンプ→第1リング（自動跳躍）→**空中でもう一度手動ジャンプ**→第2リング（自動跳躍）という攻略が必要。説明不足に加え、以前の第1リングが44×34px、第2リングが90×34pxと細く、高速でのタイミング猶予が極端に短かった。

## 何が原因だったか
- 通常ジャンプの加速度 `FIRST_JUMP=690`、重力 `GRAVITY=1900` のため、単発ジャンプの頂点は地面から約125px。第1リングの元の配置は地面から95px、第2リングは200pxの高さ。第2リングは通常ジャンプ単独では物理的に届かない。
- 以前のバージョンで、第2ジャンプの入力を+100ms遅らせると高難度速度帯の物理リプレイが失敗。プレイヤーが「ジャンプの高さ不足」と感じるのは自然な設計上の問題。
- 全体のジャンプ力を強くすると既存の19種類のコースを壊すため、**TWIN HALOのリングに絞って改善**した。

## 実装
1. `core.js` の `buildPattern` に、空中リングのみ使用する任意の5番目の引数 `ringHeight` を追加。リングの表示と物理判定が同じ大きさとなり、元の34pxリングの垂直中心を維持する。既存パターン（5番目の値がない）は変更なし。
2. `extra-motifs-v1.js` で TWIN HALO の第1リングを44×34pxから100×64pxに拡大し、高さを地面から95→90pxに変更。第2リングを90×34pxから140×85pxに拡大し、配置を0.05秒後ろにずらした。リングの見た目も一緒に大きくなり、当たり判定のずれはない。
3. 最初に触れるリングだけでなく、**第1リングと第2リングが両方必要であること・手動の空中2段ジャンプが必要であること**は変えない。通常ジャンプ能力、HP、得点、長距離難易度抽選は変更なし。
4. 試遊画面のスタート説明に「水色リングは接触で自動大ジャンプ、TWIN HALOではリングの間で空中ジャンプが必要」と追記。
5. `tests/twin-halo-accessibility.test.js` を追加し、低速から最高速で各リングの必要性、元のリングサイズの後方互換性、1回目のジャンプの±140ms、2回目の空中ジャンプの−80ms〜＋100msずれを検証。
6. GitHub Pagesでのみ試すため、新しい独立ファイル `main:playtest-v27/index.html` を作成。想定URL：`https://8mahi8.github.io/cyber-run/playtest-v27/`。既存V0.11 `/playtest-v26/` と学校Google Sites版は変えない。
