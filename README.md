# CYBER RUN — candidate V0.6 (development only)

高速エンドレス・アクションランナー。ブラウザ1ファイルへ結合できるHTML/CSS/JS。無料運用。

## V0.6で変更したこと
- 速度: 400→最大1,150 px/s。最高速度に達するまで約100秒。
- 操作テーマの短いアクションコース28種類。序盤から地上・空中・トンネル・動く障害物を混在。上下2段の足場を登るコースも追加。
- **ジャンプ台を新設**。踏むと強く跳ね上がり、任意で二段目のジャンプが可能。新ボタン不要。
- 一方通行の空中足場、自然落下、高速ジャンプ・しゃがみ連携を継続。
- 空中足場コースの抽選比率を上げ、同一テーマの連続を抑制。
- 各コースで当たり判定に合格した微小な配置バリエーションのみ抽選。ゲーム本体と突破検証の判定位置も統一。
- 速度上昇時の配置時刻を移動距離の積分から計算することで、実機と検証の時刻差を減らした。
- iPad相当の画面で先のコースを見やすくするためカメラの横幅を調整。
- 距離スコアだけ。コイン廃止済み、HP3、レア回復は維持。ランキングは未実装。

## 品質管理

- Node.js: `node --test tests/*.test.js`
- 乱数100シード: `node tools/gameplay-quality-gate.cjs`
- 実ブラウザでの各種入力とスクリーンショット: `python tests/visual_play.py`
- QA専用操作スクリプトを実ブラウザで使った長時間リプレイ: `python tests/autoplay_browser_qa.py`。QA版では内部入力を操作しているが、通常ゲーム本体には自動プレイを入れない。
- Chromiumでの検証は学校iPad Safari実機検証の代替にはならない。
- 2026-10-22: Node.js自動テスト25件成功。100シードの生成監査で序盤空中32.2%、動く障害物50区間/30秒サンプル。配置の偏りは定期的に再計測。
- 速度別・入力±40msのリプレイと80乱数シード×32区間のランダム生成検証を実施。実キャラとの6px判定差を解消。
- QA専用の想定入力で、スマホ・iPad等4画面×計16回の120秒走行（最大速度1150）を完走、HP3維持。現実の指操作で同じ成功率を保証するものではない。
- 無操作・ジャンプ連打などの雑な入力では早期に敗北することを確認。楽しいかどうかは操作の質と視認性の主観レビューが別途必要。

## 公開方針

現時点の自己評価では技術的に改善しているが、演出と爽快感の最終審査は未合格。CIの合格は面白さの保証ではない。

**ユーザーのプレイ評価と自己レビューで合格するまでは、GitHub Pages公開元のmainを変更しない。** Google Sites版もまだ変更しない。

## 棒人間キャラクターアニメーション

- 2026-10-22: 既存の箱型キャラクターを **ネオン棒人間** に変更（開発ブランチ）。
- `stickman.js` で腕・脚の関節を描画し、走行時は交互に動く。速度に応じて走る周期を変える。
- 通常ジャンプ、2段ジャンプ（手足を広げる）、落下、しゃがみ、ジャンプ台によるブーストにそれぞれ専用ポーズを定義。
- 27pxのしゃがみ姿勢、48pxの通常姿勢に収まり、**ゲームの当たり判定・移動速度・コース生成は変更しない**。
- 棒人間はCanvasだけで描画し、画像ファイルや外部ライブラリ不要。学校iPad Safari向けに追加コストなし。
- Node.jsのポーズ・シルエットテスト9件と、Chromiumでのスマホ/iPad相当の描画、実タッチイベント、120秒走行を確認済み。
- GitHub Pagesの`main`にはまだ反映しない。V0.6のゲーム性評価ゲートは維持。
